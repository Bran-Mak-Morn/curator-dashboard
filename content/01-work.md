### VSCodium
Simple, lightweight working environment for my workflow: Python code, web app development, Markdown files, Marp presentations, Mermaid graphs, Jupyter files, and HTML & CSS. 

It is a real playground, R&D and a base. No telemetry or tracking. Easy to extend with plugins. Open-source & independence.

**IDE · BASE · HUB**

### Thonny
Environment for simple Python programming. Great for quick demonstrations. 

No. 1 for programming hardware - **microcontrollers** like ESP32.

**simple IDE · BACKUP · DEMONSTRATION · HARDWARE**

### Windows + WSL / Linux
WSL provides a Linux environment in Windows for development and command-line work.
I use it as a bridge toward Raspberry Pi and for work protyping with other Linux-based systems.

**LINUX · CLI**

Great version control system. Place for developing & hosting projects (apps, scripts, code, web sites, dashboards..).

### Markdown
I use Markdown file for most of my notes, documentation, articles, prompts for LLMs and agents and for my projects content.

I like its simplicity and that it has just the few formats I actually need for any text

**NOTES · DOCUMENTATION**

### Marp
Markdown-based presentations tool - a text-first slide workflow. Easy to edit as it is just plain text.

Perfect for technical teaching and smooth slide generation. No extra features that would distract me.

**PRESENTATIONS**

### Mermaid
Text-defined diagrams for flowcharts, systems, sequences and simple architecture maps. 

Graphs are displayed beside the explanation in the same file. Easy to revise, version and reuse.
